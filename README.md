# Amber-QMMM-HPC-Tutorial-Arabic

**Practical Arabic guide to running Amber/SANDER QM/MM simulations on an HPC cluster, starting from CHARMM-GUI output.**

A hands-on **Arabic** tutorial for running QM/MM simulations with AmberTools/SANDER on an HPC cluster, assuming the AMBER
files produced by CHARMM-GUI are ready and the first run keeps the QM/MM settings unchanged.

> بالعربي: دليل عملي كامل لتشغيل محاكاة QM/MM باستخدام AmberTools/SANDER على السيرفر انطلاقاً من ملفات CHARMM-GUI.

## What's inside

- `Amber_QMMM_HPC_Tutorial_AR_v2.docx` - the full tutorial (Word). Cluster paths inside are examples.
